OpenAI 断供 Cursor：你的活押在别人模型上，收走时不会问你

发表于 2026-08-30 更新于 2026-09-11 分类于 观点 阅读次数： 本文字数： 3k 阅读时长 ≈ 3 分钟
OpenAI 官宣 11 月 12 日终止向 Cursor 供应模型，通知期 75 天；2025 年 Anthropic 切 Windsurf 只给了不到 5 天。我盘了一遍自己押在别人模型上的活，最重的那注不在 Cursor。

Hello，我是飞飞。

先问你个问题：你手里的活，有几样押在别人模型上？

8 月 28 日，OpenAI 在官方博客替一批人公布了答案：终止向 Cursor 供应 OpenAI 模型的合同，11 月 12 日生效，通知期 75 天，没人被问过一句。两周前我刚写完《4 月我写下 5 条判断，现在 Cursor 真被买走了，对了几条？》，当时觉得这个故事的下一集怎么也得等到年底。结果续集两周就来了。

4 月 21 号那天早上，我是被手机推送叫醒的，Cursor 还开着，Composer 里一段 React 改到一半，右边另开着一个 Claude Code 终端。这次没等推送，刷时间线刷到的，Cursor 就开在屏幕左边，跟那天一模一样的位置。我第一反应是点进 OpenAI 的官方博客对原文，看完才敢信，然后把那 5 条判断在脑子里过了一遍，发现有一条的兑现方式，跟我等的不一样。8 月 17 号那篇我写过：「我明白那个时刻迟早会来：某一天 Grok 已经在某类任务上追上了 Claude，Cursor 给它的默认权重更多，价格还更低。」我以为变化会从 Cursor 那头慢慢渗过来，Grok 的权重一点一点往上抬，渗到没人觉得疼。现实是刀从供应商那头直接下来了。

4 月那句「其他所有在 IDE 层做套壳的工具，都会被迫选边站」，这次算是兑现了，只是兑现的方式比我预想的剧烈得多。顺带解释一下，套壳，说人话就是只在别人的模型外面包一层界面、自己不训模型的那种工具。

OpenAI 给的理由

先看官方口径。OpenAI 的原话是：基于跟马斯克旗下公司合作的历史经验，他们没法确信 SpaceX 会按自己的服务条款来用 OpenAI 的技术。依据列了两条：马斯克收购 Twitter 之后违反过跟 OpenAI 的合同；xAI 违反过 OpenAI 的服务条款，马斯克本人今年早些时候还在宣誓下承认过。

法律依据也写明白了。OpenAI 跟 Cursor 的定制合同里有一条：公司控制权变更之后，OpenAI 只有一个有限的取消窗口。SpaceX 8 月 14 日完成对 Cursor 母公司的收购，两周后 OpenAI 就用了这个窗口。声明里还有一句要紧的：OpenAI 接下来的新模型 Astra，一开始就不会提供给 Cursor。

谁对谁错，谁在违约，谁在趁机使绊子，这些我不评，也评不了。这份声明里对开发者最有分量的信息只有一处：整件事从头到尾，决定权都不在用户手里。Cursor 不能投票，你我更不能。

这种事不是头一回

把镜头拉远一点，这已经是一条行业惯例了。

2025 年，Anthropic 在 OpenAI 收购 Windsurf 的消息传出来时，直接切断了 Windsurf 对 Claude 模型的访问。据当时多家媒体报道，通知期不到 5 天。更有意思的是，Anthropic 当时的表态里还点过 Cursor 的名字。一年之后，轮到 OpenAI 拿着 75 天通知期切 Cursor。两家的理由你都可以各自去评，但「供应商可以走人」这件事本身，已经从偶发事件变成了行业默认设置。

值得说的还有另一头：这次断供的实际杀伤，可能比标题看起来小。Cursor 的 CEO Michael Truell 出来回应，说 OpenAI 模型只占 Cursor 用户流量的大约 5%。注意，这是他们单方的口径。The Next Web 的评论更直接：OpenAI 这步棋手里的筹码比看起来薄，它是在从一个已经拥有前沿实验室的公司手里撤走一个供应商。Cursor 7 月就有了 Grok 4.5，SpaceX 用 Cursor 的数据联合训练出来的，所有付费套餐都能用。早期 Grok 的编程底子我亲手测过一回。Grok Code Fast 1 刚出那阵，我让它改 Next.js 的路由配置，它给我的是 Next.js 12 的老写法，我的项目是 15。同样的活丢给 Claude Sonnet 4.6，它先反问我项目用的哪个版本，再动手。不到两年，Grok 4.5 已经拿 Cursor 的数据练到了旗舰档。这个速度，就是 OpenAI 这步棋筹码更薄的另一半原因：Cursor 手里早就有牌了。

不过我想提醒一句：5% 是它全平台的平均数。对重度依赖 GPT 系模型的那部分用户来说，断掉的是他们的百分之百。你属不属于那 5%，比 5% 这个数字本身重要得多。我身边做 Web 开发的朋友，过去半年里几乎没有一个还在用 VS Code 裸开，要么 Cursor，要么 Claude Code 的插件，这批人手里的活，现在都值得按刚才说的过一遍账。

我盘了一遍自己的活

看完这出戏，我做了件 4 月就该做的事：把自己手里的活摊开，一项一项数，每项押在谁家模型上。

数出来的账是这样的。前端 UI 的小改动在 Cursor 的 Composer 里干，底下挂的是 Claude，OpenAI 断供暂时轮不到我。后端、脚本、公众号这条 13 个 skill 的流水线，从拉选题、搜料、写稿、润色、配图到分发，八个环节全长在 Claude Code 上。这是我押得最重的一注：订阅、CLAUDE.md、长期记忆、skill 体系，全钉在这家公司的墙里，每月两边订阅加起来 40 美金出头。杂活按我那套「过秤」的规矩切给便宜模型，也是在同一家。这套规矩怎么来的我写过：一开始我逮着最强的模型往死里用，直到有个月账单肉疼，才坐下来把一篇要用的六个 skill 重新配档，额度从一个月吃掉 19% 压到 8% 到 9%。小账我算得这么细，大账反而一直没动过：这十几个 skill 连同它们的接口卡，整个长在谁家的地基上。真正握在自己手里的，只有文章的 markdown 文件、Obsidian 笔记和 git 仓库，这层谁也收不走。

还有一笔旧账要交代：4 月那条止损线，到日子我没按，原因写在那篇复查里：不敢测，怕测出来 Grok 的差距没我想象的大。现在回头看，当时怕的方向就不对。我盯着 Grok 的准头，没盯着房东的脸色。

说实话，盘完我心里咯噔了一下。我的装修，早就钉进租来的墙里了。房东要卖房，通知期多长，看合同，不看我的心情。

公平地说，这次的事对我影响很小，断的是 Cursor 里的 GPT 系用户，我两边的活都还在。可它又演示了一遍那个流程：供应商一纸公告，一批人的工具箱 75 天后集体变化，全程没人问过他们。4 月那次我还觉得这只是个长期判断，现在它开始定期上演了。

你可以今天做的三件事

这套盘账方法你自己十分钟就能做一遍。

先盘。把每天的活摊开写下来，一项标一家供应商。标完你多半会发现，重注比你想的集中。

再查退路。OpenAI 这次特意留了口子，Cursor 用户拿自己的 API 密钥，也就是绕开 Cursor、直接向 OpenAI 付费的那种方式，还能继续用 GPT 模型。你手上常用的工具里有没有类似的退路，值得花十分钟确认一遍。

最要紧的一步是落袋：给真正的资产找个自己的地方。我的文章、配置、笔记全是本地文件加 git 仓库，模型可以断，这层断不了。

我自己也坦白，退路那条只做了一半，这周补上。做过的那一半，是去年那阵风声紧的时候，我认真装过 MiMo Code 当备胎。跑是真跑起来了，token 的计价方式跟 Claude 那套对不上，算下来不划算，没留下来。但装过、跑过这一遍，我心里对换一套后端要动多少东西有了数。这个数，我建议你手里也存一个。

11 月 12 日我会再看一眼

那天是断供生效日。我会打开 Cursor 的模型列表，看看 OpenAI 那几个名字还在不在，也想看看有多少人真的迁走了，有没有哪家供应商趁机发欢迎搬家的公告。到时候有值得说的，我再写一篇。
