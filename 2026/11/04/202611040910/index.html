他们不再按用量付钱了

发表于 2026-11-04 更新于 2026-11-12 分类于 观点 阅读次数： 本文字数： 2.5k 阅读时长 ≈ 2 分钟
Revolut 把 2000 名工程师从 Claude Code 和 Codex 换到自托管 GLM，账单降到原来的十分之一。真正换掉的是计费方式：从按用量付钱改成按机器付钱。

Hello，我是飞飞。

十一月二号我写过一篇，讲额度变得越来越难算清。今天这条新闻，正好是那篇的反面答案。

按量计费真正贵的地方，是它会让人不敢用。

Revolut 把这件事算完了。它没有去换一家更便宜的供应商。它把计费方式整个换掉了。

先是从按人头封顶

这家公司现在估值约一千一百五十亿美元，欧洲最贵的私营科技公司，大约两千名工程师。

它的 AI 路线走得很慢，一步一步往上加。2025 年初先接 Gemini，据 AI 运营负责人 David Abitbol 说，编码时间降了两成，交付周期降了一成。

接着试 Claude Code。2025 年 2 月开始试，2026 年 1 月铺开。

铺开之后问题冒出来了。有工程师一个月花掉一千到一万美元，回报说不清。于是他们设了封顶，每人每月大约三百美元。

这个动作你肯定眼熟。给团队设预算、给自己设额度，多数人用的都是这一招。

三百美元这个数其实不低。一个人一年三千六，两千人就是七百二十万美元。他们算完发现，这笔钱花下去换回来的效率，说不清。

封顶之后出了什么事

封顶把账单按住了，也把人的用法扭曲了。

一个被额度卡住的人，不会挑最难的活去交给 AI。他会挑最安全、最省 token 的那件。这跟努力不努力无关，是没人想在月底被叫去解释一笔超支。

于是 2026 年 4 月，他们开始自托管开源模型，选的是智谱的 GLM 系列，起步 5.1，现在默认 5.3。五十六张 B200 显卡，服务全部两千人。摊下来一人不到百分之三张卡。这个密度说明他们不指望一张卡伺候一个人，靠的是排队和调度把利用率顶上去。

从铺开到自建，中间只隔了三个月。

换成按机器付

Abitbol 报的数是这样：混合成本约 0.3 美元一百万个 token，账单降到原来的十分之一。

我更在意他另一句话。他说开源现在是公司的优先项，理由是经济上划算、账单是平的、月底不会有账单惊吓。

他们押的其实是另一件事：用量会一直涨。涨到机器满负荷，单位成本才真的掉下来。反过来，哪天人少了，那堆卡就是沉没成本。

平，是整件事的关键词。

按量计费最难受的地方从来不在单价，在那个「不知道月底多少」的悬着。悬着的时候，人会保守，会省着用，会把最该交给 AI 的那件活留着自己做。

0.3 美元一个百万 token 这个数，也不能直接拿去跟别家比。它是边际成本，不含五十六张 B200 的采购、不含机房和电、也不含那个能把推理调到能用的团队。

说白了，他们把一笔按用量付的钱，换成了一笔按产能付的钱。用量小的时候，后一种更亏，因为你买的是机器，时间到了照样计费。你要是动过自己搭一套的念头，先算这一笔：人少了，机器不会少。

换上不等于能用

开源权重下载下来就能跑，这话没错。跑起来能不能用，是另一回事。

开箱表现很糟，这是他自己承认的。他们花了好几个月调，把首 token 时间从十秒以上压到一点六秒。十秒是按下回车，你能把上一段话读完，屏幕上还是空的；一点六秒是你手指还没离开键盘。

这段时间里，需求从每秒三次请求涨到七次以上，显卡一张没加。

靠的是量化、把 prefill 和 decode 拆开部署、再加一轮超参调优。他说得很直白，这些提升来自推理优化，跟加算力没关系。

现在他们的目标线是三秒，超过五秒工程师就会抱怨。白天每人每秒两百个 token，下午五点以后卡闲下来，能到八百。

省下来的钱里，有一部分是从别处搬过来的。搬的是工程能力，是几个月的调参，是一个团队蹲在指标前面盯着首 token。

那两个百分数要打折

他们还报了另外两个数：编码时间快六成，交付周期好七成。

这两个数我只当参考用。

跳升的时间点正好是四月，也就是同时发生两件事的那个月：切到 GLM-5.1，并且不再限 token。模型换了一个，限制也拿掉了，两个变量搅在一块，要说是模型带来了六成，证据不够。

我对这两个数的态度，跟对任何自报成绩一样：听，但不拿来当结论。

不过里面有个细节更有意思。交付周期的改善幅度，比编码时间还大。

他们自己的解读是，写代码本来就不是主要瓶颈。工程师不用再担心额度之后，开始把 AI 用在别处：翻内部文档、查邮箱、处理 Jira、读 Slack 里的需求。

一个额度封顶，封住的不只是 token 的数量，还封住了人对「这东西还能拿来干什么」的想象。

他们也没有全搬

有件事得说清楚，否则这条新闻很容易被读成另一个意思。

Claude Code、Codex、Gemini 三样，他们一个都没停用。它们留着处理专门负载，包括图像识别。自托管的 GLM 承担的是大部分编码任务，大部分不等于全部。

模型权重是下载到本地跑的，推理放在 Revolut 自己的美国机房，不往中国托管的端点发请求。这是给监管看的答案。

法国媒体 Numerama 在报道里补了一句：他们回应的是数据流向的顾虑，对模型本身以及它生成的代码有什么风险，没有细说。

这条线还有下一步。据 AIM 报道，公司 CEO Nik Storonsky 十月说过，Revolut 正在开发用客户交易数据训练的自家模型，他提到的数据来源是这家公司每天三千万到四千万笔交易。自托管别人的开源权重是第二站，第三站是自己造。

落到你自己身上

我没跑过 GLM。六月那篇里我写得很清楚，那些跑分是智谱自己报的，我一个字没验过。今天这篇的数字也全来自公开报道，同样没有一条出自我这双手。

我能给的只有我这一侧的体感。我按月付订阅，被限流卡过，也在写稿最顺的时候停下来算过余额。那种感觉跟钱多钱少关系不大，跟确定不确定关系很大。

所以这条新闻对我真正的价值，是换了一个提问方式。

你每个月付的那笔钱，有多少是在买模型，有多少是在买「不用算」。

如果买的是前者，更强的模型出来了，你就得跟着升级，账单该涨还是涨。如果买的是后者，那这笔钱真正的成本就不在模型上，在你敢不敢把用量放开。

他们选的是自己把那个判断接过来。代价写在明面上：五十六张卡、一个机房、一个能把首 token 调到一点六秒的团队，还有几个月的调参。

我猜绝大多数人接不住这个代价。摊到个人身上，这条路反而更贵：你摊不平一个机房，也喂不满那堆卡。它只在一种规模下成立，就是人多到能把机器跑满。

但知道有人接过、也知道他们接完是什么样子，这件事本身有用。至少下次你看到额度规则又改一版，知道还有一条路叫「不租了，自己买」。

轮到你：如果你的 AI 工具明天改成严格的按量计费，哪天你会真的退订？给我一个具体的触发点，别只说「看情况」。
