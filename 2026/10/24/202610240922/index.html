三天前我立的 9 分之问，月之暗面交卷了

发表于 2026-10-24 更新于 2026-10-26 分类于 AI 阅读次数： 本文字数： 3.1k 阅读时长 ≈ 3 分钟
月之暗面Kimi K3.1 Pro以55分列AA总榜第五，三天前Step5篇立的9分之问被回答。但答案有三处意外：靠后训练而非参数堆料、权重11月4日才放开源第一暂欠、Terminal-Bench 65.7%超GPT-6 Astra。

Hello，我是飞飞。

先把三天前那道题原样摆回来。九月二十号我写阶跃 Step 5 时留了句话：当时开源最高 GLM-5.3 四十五分、K3 四十四分，闭源 Fable 5.1 和 GPT-6 Astra 都在五十三，中间隔着九分，「这 9 分是所有国产开源旗舰共同的下一道题」。今天凌晨，月之暗面交卷了。我打开 AA 榜单从上往下数：Opus 5.5、Sonnet 5.5、Opus 高推理档、Muse。数到第五行，才是 Kimi K3.1 Pro，五十五分。

九分，三天，填平了。你要是只看到这儿，大概率觉得又是一次「国产开源追平海外」。但我对着官方公告和榜单核了一上午，卷面上有三处意外，比分数本身有意思得多。先给结论：这题算是答了，但答案的形状谁都没押中。靠的既非参数也非架构，是后训练硬堆；「开源最强」的头衔此刻还欠着；还有一笔账变了，跑 agent 的价格表，输入价涨了八倍。至于上次存疑的 12.6，也顺带被翻了案。

卷面之一：分是堆出来的

最意外的是答案的路径。官方原话说得很明白，K3.1 Pro 是 K3 的后训练版本，substantially larger post-training compute，翻译过来就是同一个底子，后训练的算力狠狠加了量。怎么加的他们也讲了：大规模跨下游域联合强化学习，而且把整条栈捋了一遍。强化学习框架、长上下文推理、训练效率、沙箱基础设施，每一层都动了。他们给这套投入定的目标是让 RL 算力换来「稳定、可预期的回报」。

三天前那篇我猜「下次比的是谁用更小的身板拿到同样的分」，指望着参数效率轴继续卷。月之暗面走了另一条路：身板一克没减，还是 K3 那个 2.8 万亿总参、千亿级激活的架子，靠后训练把分数硬顶上去的。阶跃在改身板，月之暗面在堆后训练，两条路线这下都摆在了台面上。下一道题可能换了问法：开源何时追平闭源问完了，接下来该问堆后训练和改身板，哪条先撞天花板。

除了综合分，几个分科成绩值得单列。Terminal-Bench 4.0 拿 65.7%，官方口径超过 GPT-6 Astra 的 58.2%，只比 Claude Opus 5.5 的 66.4% 差一点点。自家的 Kimi Code Bench 3.0 长程任务从 K3 的 55.95% 提到 61.2%。带工具跑 BenchCAD（3D 建模代码生成）92.7%，离 Opus 5.5 的 96.2% 不远。你要是拿模型写脚本、跑任务，这几格才跟你的日常工作有关，其余的分看个热闹就行。金融文档问答 OfficeQA Pro v2 拿了 64.4，官方称当前最好。自家出题的部分照旧按宣传看，带第三方对标的几项可以记下。

12.6 和 65.7 之间隔着五倍，两个数字必有一个口径有毛病。是当时报道引错了，还是评测档位不同，我没核到定论，不替它们下结论。但当时那笔「存疑」的账，现在看是记对了。

卷面之二：头衔还欠着

第二处意外更微妙。「3T 级开源最强」这话官方说了，我核了榜单，此刻却不能照抄成「开源第一」。

Artificial Analysis 的开源权重榜上，现在排第一的是 MiMo-V2.6-Pro，四十六分。K3.1 Pro 的五十五分挂在总榜第五，前面是 Opus 5.5 的 58、Sonnet 5.5 的 56、Opus 5.5 高推理档的 56、Muse Wonder Full 的 56。为什么分高却不算开源第一？因为它的权重要 11 月 4 日才放，今天它只能挂在 API 侧的榜单里。

这里有个口径差得摆开。不少报道写「位列第 4」，那是按模型家族数的：排它前面的 Opus 5.5 和 Opus 5.5 高推理档是同一个模型的两个档位，合并算就只剩三家。按榜单条目数是第 5，按家族数是第 4，两个数都对，引用的时候得说自己数的哪一种。另外「较 K3 提升 11 分」这个说法出自 AA 的文章，K3 当前在榜的确切分数我没在页面上核到，四十四分是 9 月 20 日那篇写作时的口径，引用时同样带上时间戳。

所以准确的说法是：分数到了，头衔没到。等权重一落地，开源榜第一直接从四十六跳到五十五，一次抬九分。这个「欠着」的状态大概还能维持十天，到那天我这篇还得再还一次账。

顺带记一笔格局：九月的五十三分俱乐部（Fable 5.1、Astra）已经整体被挤出了前五，闭源那边 Claude 5.5 两档和 Meta 的 Muse Wonder Full 接了棒。开源在追，靶子自己也在挪。

卷面之三：账变了

最后一处意外在价格表上，跑 agent 的人最该看这格。OpenRouter 的口径：K3 时代输入 $0.238、输出 $24 每百万 token；K3.1 Pro 变成输入 $2、输出 $10。

输入涨了八倍多，输出砍了一多半。这个结构变化对长上下文用户是实打实的：Claude Code 每一轮都要重发系统提示和全套 skill 描述，输入单价才是缓存之外的大头。我的会话结构是读多写少，一整个工作日里输入 token 的占比远高于输出。这种用法对输入单价最敏感。拿九月报道里的行业中位数比（输入 $1.88、输出 $10，口径有时效），K3.1 Pro 的输出贴着中位，输入反倒高于中位。输出便宜了当然好，但我这种重上下文用户，先得算输入那八倍涨了多少。

还有两个数字值得单独记。一个是幻觉率：官方给的口径，从 K3 的 23.4% 降到 8.3%，出自他们自家的压力测试榜，不代表日常使用错误率。就算打个对折看，agent 跑长任务最怕的就是中途编造，这个方向的改善比榜单排名实在。另一个是高速版：2 到 3 倍速对交互体验是明显的加分项，但高速档通常意味着更高的单价或更少的额度，账得等 pricing 页挂出来再细算。

卷外两笔

真要用起来，今天就有两条路。Kimi 开放平台和 OpenRouter 都已挂了标准版，另有 kimi-k3.1-pro-highspeed 高速版，同一模型的快慢两档。API 客户端还可以勾 Zero Data Retention，对话数据不留存。我自己还没充钱跑，理由跟上回对 Step 5 一样：发布头几天的第三方实测还没铺开，我不当那个验证的。

安全侧也有一笔值得记。官方披露他们做了数据清理，网络安全基准 xdev-bench-hard 的清理前检查点 pass@3 是 90.5%，清理后掉到 81.0%，并称净能力落后于闭源前沿。换句话说，11 月 4 日放出来的那份权重，是被主动削过攻击能力的版本。这跟评测越境那一串事之后的行业原则是一条线：开源可以，攻击能力的前沿不外放。

把尺子收回来

三天前那篇立的东西，逐格对账。九分之问，验中，答法是后训练。体积尺，K3 那 594G 我搬不动，K3.1 Pro 同为 3T 级，结论原样适用，本地玩家这局还是旁观。12.6% 那笔存疑，被 65.7% 反转，反转得我挺舒服。价格表，结构变了，输入贵了，账要重算。

四把尺子收回三把半，剩下半把是那个没定论的口径差，留给实测。还有把尺子在悄悄升级：上个月写 DeepSeek Flash 拿开源第一那回，说的是网页榜；这回开源第一的战场换到了 AA 综合榜，含金量的尺子本身在往上走，这是比单次排名更值得盯的趋势。

体积尺多说一句。七月 K3 权重开放那天我列过四条不搬家的理由，如今订阅补贴、skill 迁移成本、自托管门槛那几条原样有效，唯一变化的还是能力那一格：当时官方自己承认落后于闭源旗舰，这回 55 分摆在这儿，那一条的理由只剩一半了。可另外三条没动，我的结论也就只改一半。

11 月 4 日权重一放，两件事排上日程：把 K3.1 Pro 接进 Claude Code 跑两天看工具调用飘不飘，再把权重体积跟 594G 摆一起复测。OpenRouter 给的定位也值得记一句：基于 K3 后训练、面向长程编码和智能体任务的多模态模型，跑长任务正是我的主场景。到时候成不成，另写一篇交账。

所以留个问题给你：开源第一的头衔还押在别人家手里十天，你觉得这十天里 MiMo 们会不会先动手，还是 11 月 4 日直接易主？
