能点鼠标了，可它还不算开源

发表于 2026-11-04 更新于 2026-11-14 分类于 AI 阅读次数： 本文字数： 2.8k 阅读时长 ≈ 3 分钟
腾讯混元 Hy4 正式版首次加入视觉与电脑操作，游戏开发评测涨 19.1%，幻觉率从 15.76% 降到 5.45%，API 价格没动。但权重只是「计划开源」，眼下能用的只有服务。

Hello，我是飞飞。

九月那篇的结尾我立了一句话，说拿判得死的初筛活喂 Hy4 一周，跑完回来交账。这笔账到今天还欠着。

今天它出正式版了。你手上有没有那种活，得自己开好几个窗口，来回看、来回点、来回搬数据？腾讯混元说，Hy4 正式版第一次能看懂屏幕上的东西，也第一次能自己动手操作电脑。

先泼半盆冷水。「第一次」有边界，「开源」这两个字眼下也只是预售。

第一次这三个字要打折

混元文章里说的「首次」，指的是它自己家的 Hy 系列。往前数，Hy4 preview 只能读文字，这次正式版才把视觉装进去。放到国产模型的大盘子里看，能看图、能操作界面这件事，通义和字节那边早就在做，不是今天才有的新鲜事。说「国产开源模型第一次」，是抬举了；准确的说法是混元自己第一次。

另一个要打折的字是开源。原文写的是「计划开源模型权重」，联合了 vLLM、SGLang 和一家叫 Inferact 的公司做生态支持，模型系统卡片也准备在那时候一起发。计划这两个字很关键。眼下你能用到它的地方，是腾讯云、OpenRouter，还有腾讯自家的 CodeBuddy、WorkBuddy、元宝和 ima。

权重没放出来，意味着你还不能把它拉到自己机器上跑，也还没法验证别人复现的那些数字。它现在只是一个能调用的服务。能不能拿走，要等权重。这个区别看着小，放到选型上就是天大的事：能调用的东西，价格和条款随时会变；能拿走的东西，才轮得到你说了算。

它多长出来两样东西

一样是眼睛。细粒度图像处理、复杂图表分析、带图的数学推理，现在能一起看。官方举的例子挺实在：随手拍一张照片，让它判断这是哪儿，再去核实。这类活以前得把图发给同事，现在可以发给它。

另一样是手。命令行和图形界面都能操作。Blender、CAD 这类专业软件做了专项训练，跨应用的长程任务也练了。官方演示里有一个是跨软件做一套 DIY 装修方案，从量尺寸到出效果图。

游戏和前端这笔账，官方也报了：GameDev 评测比 preview 涨 19.1%，GameLogic 涨 9.8%，数据是跟腾讯自己的游戏团队一起调的。引擎适配写到了 UE、Unity、Godot，多人在线刚开了个头。

手还分粗细。能点按钮是一层，能在 Word、Excel、PPT 里跟你改同一份文件是另一层。后一层更难，它得知道光标在哪儿，还得知道你在改什么，改完还得让你认得出哪句是它动的。

科研那个例子更硬。发布稿里写，给 84 张顺序打乱、还带镜像翻转的小鼠胚胎切片，一共 699 万个细胞，它在没有专用配准工具、没有细胞类型标注的条件下，一个半小时内自己完成了对齐和三维重建，全程没人插手。这个活跟点鼠标不是一回事，但它说明同一件事：模型开始能把一件长活从头推到尾。

这些数字都是腾讯自己报的，我照抄，不替它背书。它点得准不准，要等权重放出来，等第三方在真机上跑一遍才算数。

最该看的是幻觉率

发布稿里有一节讲金融。213 位专家做众测，其中 153 位来自外部头部机构，七成有五年以上经验，一共 579 个真实任务。众测得分是 Hy4 3.04，Kimi K3.1 Pro 和 GLM-5.3 都是 2.68，DeepSeek-V4.1-Flash 2.97。跟自家 preview 比，在讯兔科技的内部评测里高了 12.03 个百分点。

这些数里我最在意的是后面那句：幻觉率从 preview 的 15.76% 降到 5.45%，靠猜导致的错误从 23.1% 降到 5.6%。

为什么要盯这个。你要是让一个模型自己坐在那儿点鼠标、填表单、发消息，它最可怕的毛病在于错了还特别笃定，这比不会更麻烦。跑分决定它能干多少活，幻觉率决定这些活里有多少要你回头重做。5.45% 大概是原来的三分之一，这个降幅比涨几分更能说明一件事：它能不能被放到没人看着的地方跑。

价格那条也反常。发布稿的原话是，性能显著超过 preview，同时维持相同的 API 价格。加了视觉，加了电脑操作，参数规模也扩了，账单上的数字没动。这种定价看着不像按成本算的，更像按抢地盘算的。

点错了没有后悔药

我最想聊的是这个。写代码这件事我天天交给 agent，敢交的底气不在它多聪明，在它每一下都落在仓库里。改错了，diff 看得见，回滚一条命令。有回它把一个七千行的老项目翻成另一种语言，切着上下文往下走，把前面改过的字段忘了，回头又改坏一处。我是顺着 diff 一点点倒回去的，大半个下午没了，但东西还在。

桌面不一样。它能看见你的屏幕，能移动鼠标，就意味着它能点到那些按钮上。这个域里没有 diff。点错一个「全部删除」，发错一封邮件，付了一笔不该付的钱，事情发生了就是发生了，没有一条命令能退回去。

腾讯自己也写了一段安全说明。训练时只纳入防守性网络安全数据，漏洞利用、逆向、渗透这类攻击性内容全剔掉了；生物这块，开放实验设计能力的自评分是 30.4 分（满分 100），跟前沿模型差得明显，他们据此判断还没到能降低危害门槛的程度。厂商愿意把这些写进发布稿，说明放权的边界本来就得有人守。

所以「能操作电脑」这件事，真正要问的不是它点得准不准，是它点错的那一下，你赔不赔得起。

哪些活我敢先交

我的分法很简单，按「错了能不能重来」切两半。

能重来的，全交。翻页面找资料、把几个后台的数字抄进一张表、跑一遍固定流程看有没有报错、把一堆截图里的信息认出来归类。这些活错了的代价是重做一次，最多浪费十分钟。

不能重来的，攥着。删除、提交、付款、发消息，还有任何按下去就收不回的确认键。这类活我宁可让它停下来问我一句，也不让它自己判断。

除了能不能重来，还有一条：出错的时候我能不能发现。代码域里 diff 会自己把问题摆到我面前，桌面不会。它在你没打开的窗口里改了一个设置，你以为那儿没动过。所以放给桌面的活，我会先让它把打算点的步骤列出来，我扫一眼再放行；动完再让它把做过的每一步写下来。这两道都是我自己另外加的，系统不自带。

另一类活卡在读写之间。Hy4 接上 WorkBuddy 的企业微信套件之后，能读你的聊天记录、邮件、文档、日程和会议，帮你理清几个项目各自的进度，提醒你快到期的事。让它读、让它整理、让它提醒，这些我敢放；让它替你回一条消息、改一份共享文档，就得看对面是谁。

欠的那笔账怎么还

那笔账没交上。这一周我没真拿它跑过活，今天这篇照发布稿和官方数字写，算资料解读。我不会给你编一个「跑了一周发现它如何如何」的故事。

补账的计划没变，只是得等两件事。一件是权重真的放出来，那样我能在自己机器上跑，不用管渠道排队；另一件是 Hy4 flash，官方说近期会发，主打便宜和快，那种型号才适合天天喂。在那之前，我最多做几次单点试验，不会写成一周的结论。

你要是有能重来的活，现在就能试。腾讯云和 OpenRouter 都上了，价格跟 preview 一样。试完回来告诉我一件事：它点错的时候会停下来问你，还是自己绕过去接着点。这个问题比跑分有意思。
