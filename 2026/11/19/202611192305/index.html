代码 ANT 今晚敲钟：我给它交了两年 Token 费，终于等到了这份万亿账本的终局

发表于 2026-11-19 分类于 观点 阅读次数： 本文字数： 2.7k 阅读时长 ≈ 2 分钟
股票代码 ANT 定价 83 美元敲钟。Anthropic 凭 1.5 万亿美元市值创下历史纪录。一个天天交 Token 费的开发者，终于兑现了两个月前的对账承诺。

Hello，我是飞飞。

如果你日常也开着命令行终端写代码，我想先问你一个非常私人的问题：这两年你在 Claude 身上花掉的订阅费和 API 账单，加起来到底有多厚了？

两个多月前的 9 月 5 日，我在写《我说它秋天上市，它推迟了，可账变好看了》那篇文章时，在文末立下了一个路标。当时外媒传闻估值要奔着两万亿美元去，我说这笔账押的是四倍增长的赌注，赌注能不能兑现，等它招股书揭盅挂牌的时候，我一定要再回过头来对一次账。

今晚，这只靴子终于以最震撼的方式砸在了地毯上。

纳斯达克的大屏上打出了股票代码“ANT”。发行价敲定在每股 83 美元，共计募资 813 亿美元，完全稀释后的总市值直接冲上了 1.5 万亿美元。这个体量一举超越了今年早些时候上市的 SpaceX，正式成为人类商业历史上规模最大、估值最高的一次首发上市。

作为每天在终端里敲 claude 命令、每月真金白银给它贡献 Token 费的几十万开发者之一，看着代码 ANT 敲钟的那一刻，我有一种极度奇妙的荒诞感与笃定感。

荒诞的是，三年前这还只是一家从 OpenAI 出走、被嘲讽为过于理想主义的边缘团队；笃定的是，这份惊天账本里的每一行数字，背后都是我们这一批被它彻底重构了工作流的打工人。

两个月前吹的牛，全兑现了

9 月初外媒爆出 Anthropic 计划冲击两万亿市值的时候，科技圈里质疑的声音铺天盖地。很多人觉得这无非是投行在降息周期里编造的又一场估值泡沫。

可当所有招股文件和挂牌数据摊在桌面上时，你会发现这笔账算得极其冷酷且硬核。

公司披露的年化营收已经稳稳越过了 470 亿美元。更可怕的是它的净金额留存率，也就是业内常说的 NDR，居然维持在惊人的 900% 左右。这个指标翻译成大白话就是：老客户不仅没有流失，反而随着对智能体工作流的依赖加深，第二年在它身上花出去的钱，平均是第一年的将近十倍。

10 月底的时候，很多人拿着招股书里上半年净亏损 807 亿美元的数字大做文章，甚至有人宣称 AI 巨头正在流血狂奔。我当时专门写过一篇拆解，把那笔亏损的明细一层层剥开给读者看。

在那 807 亿里面，有整整 724 亿是因为亚马逊早期买入的可转换票据，按照会计准则在估值暴涨时做的公允价值重估。那根本不是真实的真金白银亏损，而是一笔只留在报表上的数字游戏。除掉这些非现金波动，它上半年的实际经营现金流是正向的 39 亿美元，调整后的经营利润更是实打实盈利了 16 亿多。

华尔街的精明资金没有被表面的巨额亏损吓退。813 亿美元的新股发行被各大主权基金和机构投资者瞬间扫空，散户抢购的资金量更是创造了历史极值。

两个月前大家以为是在吹牛的增长预期，最终以每股 83 美元的定价，完完整整兑现在了纳斯达克的行情看板上。

换掉它，我交过真金白银

这家公司高达 1.5 万亿美元的估值底座，究竟是什么做成的？

它不是靠手机里陪人闲聊的免费伴侣堆出来的，也不是靠生成几张花哨图片的噱头吹出来的。它八成以上的真金白银，全部来自企业级 API 和开发者工具链。

这里面的核心动力，正是今年席卷整个编程圈的 Claude Code。从零做到年化 25 亿美元的营收，它仅仅用了九个月。开源社区里甚至有统计显示，GitHub 上有数以万计的代码提交，正是由这个命令行智能体在后台默默完成的。

很多同行好奇，为什么这帮写代码的工程师愿意源源不断给它交钱？难道市面上没有更便宜的替代品吗？

这事我必须交代自己的底细，因为我亲自交过极其惨痛的学费。

今年 6 月份的时候，我也动过精打细算过日子的念头。我想着平时写写小脚本、跑跑格式化，干嘛非要一直烧昂贵的旗舰模型？我尝试把一部分长链路的流水线任务，切到号称性价比极高、便宜了七八成的第三方模型上。

结果呢？刚跑了几步，长上下文的后半截就开始逻辑散架。工具调用的结构彻底飘移，本来要求输出纯文本的地方吐出了一堆报错代码。为了排查一个隐蔽的参数错误，我坐在电脑前生生手动调试了两个小时。两天折腾下来，手头正经项目的进度完全停滞，我只能老老实实切回了 Claude。

从那之后，我再也没有动过省这笔钱的心思。

当你的项目架构、日常规则、自动化工作流全被一套工具链深深锁死时，它的迁移成本高得令人绝望。每月固定 20 美元的订阅，加上根据任务量浮动的几百元 API 费用，对我来说不再是可有可无的软件消费，而是每天早上睁开眼就必须投入的生产资料。

全世界上百万和我有着同样选择的开发者，每一次在终端按下回车，都在为这个万亿帝国的飞轮注入一滴润滑油。

当公益信托遇上万亿资本

Anthropic 身上最让资本市场纠结、却又最让开发者心安的地方，是它极其奇葩的治理结构。

它从成立第一天起就注册成了一家 PBC 公共利益公司，头顶上悬着一个名为长期利益信托的特殊委员会。这个委员会不持有经济利益，却在董事会里握有关键的表决权。按照章程，如果他们判定某个模型的演进威胁到了人类安全，他们甚至有权勒令叫停整个商业化进程。

就在前不久，五角大楼试图把它的模型接入军用选标体系，这家公司硬生生以违反安全准则为由拒绝了对方，甚至一度被相关机构列入了黑名单。

换作十年前的华尔街，这种把商业利益排在理想后面的做法，必然会被资本市场狠狠惩罚。但这次挂牌的结果却彻底颠覆了传统认知。

在智能体能力越来越强、越界风险越来越高、动辄引发系统级翻车的今天，这家公司把安全边界焊死在企业基因里的执拗，反而成了大企业最放心的背书。

财富百强企业里有八成采购了它的服务，它们买的不仅是顶尖的推理智商，更是那份不会为了抢发版本而悄悄兜售隐私、越狱跑偏的底线确定性。

资本最后用 1.5 万亿美元的定价证明了一件事：在充斥着不确定性的 AI 狂潮里，克制与严谨同样是一种极高溢价的生产力。

对完账，明天继续开终端

今天晚上，科技媒体的头条注定会被 813 亿、1.5 万亿这些晃眼的数字彻底淹没。

但我更想记录下的，是那些被宏大叙事遮蔽掉的细碎日常。

三年前，当第一批大模型横空出世时，几乎所有的预言都在宣称程序员这个职业将会在短时间内彻底消失。但三年后的今天，一家完完全全靠开发者作为主力支撑的公司，站在了全球资本市场的最顶峰。

它没有消灭程序员，而是把每一个普通开发者的双手，武装成了可以同时调度多条流水线的软件工头。

两个月前的对账承诺，在今晚画上了一个完美的句号。四倍增长的赌注他们打赢了，万亿市值的狂欢他们也接住了。

但对于屏幕前的你和我来说，敲钟散场之后，明天清晨的第一缕阳光洒下来，我们依然要准时打开黑色的终端窗口。

在那行闪烁的光标前面，代码 ANT 的涨跌其实并不重要。重要的是，敲下回车之后，那个安静的智能体依然能准确无误地帮我们把下一行代码写完。

账本对完了，生活还在继续，我们的活儿也该继续干了。
