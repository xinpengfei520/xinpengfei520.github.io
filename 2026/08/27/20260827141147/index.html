代码里能反悔，网页上没有撤回键

发表于 2026-08-27 更新于 2026-09-09 分类于 产品 阅读次数： 本文字数： 2.4k 阅读时长 ≈ 2 分钟
Claude 官方让它在浏览器里免审批自己点，我却没敢全松手：它自动批准的是它判定安全的动作，而网页操作没有代码那种 git diff 和撤回键可兜底，提交删除这类撤不回的我还是自己按。

Hello，我是飞飞。

Claude 把浏览器这扇门又推开了一截。Claude in Chrome 正式全面上线，面向所有付费套餐，还能免审批自己在浏览器里操作。看到这条，我说的第一句不是”又来了个吓人的功能”。那堆翻后台、搬信息、填表单的重复活，我早就不想自己干了。

这方向是真有用。说真的，谁天天在网页上干重复的点点点，查后台、跑固定点击、把页面信息搬进表，都会觉得，能看屏幕自己点的 agent 早该来接这活。它来得正是时候，我先把这句认下，免得写成像我这号人对着新技术念叨”危险危险”的抬杠稿。

可认完这句，我七月那句话就又冒出来了。上个月 Claude Code 把浏览器塞进桌面版，我写过一篇《浏览器住进了 Claude Code：agent 抓网页省掉一层，但我只敢先让它看》。那篇的标题就是我的态度：让它看，行；让它动，先等等。这回它自己上线了，还免审批，”动”这档子事，直接推到我跟前了。

它来得正是时候

先把”正”的一头说清。能看屏幕自己点的 agent，是去接那些本就不该人盯的活。翻页、读正文、走固定流程，都是可重来的，点错了刷新一下就回来，让 agent 干，省的是我的时间，风险是零。这一类的活，我向来敢交。眼下就有这么一件：让它帮我扒页面上那串数，它点进去、读出来、整理好，我这边接着写稿子。这就是我最想交给它的活。

我犹豫的，从来不是它有没有用，是它动手的代价跟写代码不一样。

我的尺子就一条

给 agent 放权，我只有一条土规矩，按”点错能不能收回来”分。

读得到、查得到、能重来的活，拉日志、算数、找异常、只读巡检，我全交，现在就是全交给它跑的。

会改线上状态、会碰凭证、会发出去的活，缰绳勒紧，宁可它停下来问我一句。

为什么这么分？因为我天天让它改真实代码，那个域有 git。它改错任何一处，diff 里看得见，我一个 reset 就回去了。

可我在网页这头栽过一个跟头，让我明白这里没这个福利。有回我手一滑，把一条域名解析指向改错了，当时没觉出什么，过了几分钟站直接打不开。改回去倒不难，可解析生效要慢慢等，那几分钟我盯着一直打不开的站，只能干瞪眼。那次我记下的一句话就是：不可逆的操作，太早交给了还会犯浑的东西。

代码和网页不一样

改代码和操作网页，是两套兜底逻辑。

改代码，agent 再莽，也是在我划定的仓库里动。它改了哪一行，diff 里看得见、回得去，大不了 reset。这是代码域自带的保险丝。我不是没给过它大的。我让 Claude Code 把一个个老项目整库翻新，代码量不小，它一把梭下来，改错的地方都在 diff 里，我一条条盯得住。这就是代码域给我的踏实：它再怎么造，我都有个后视镜。网页这一头，没有这个后视镜。

它坐在我登录态里替我点。它点的每一个”提交””删除””发送”，没有 diff 给我回看，没有草稿箱兜一道，按下去就是真提交、真删除。它免审批之后，这层”替我做不可逆操作”的门，是实打实开着的。

我说这些是吃过亏的。我手里有串钥匙：git push 权限、图床密钥、公众号 key，平时用着真香，出事的时候你才知道它有多沉。有一回我 GitHub 的 token 权限给得太宽，Claude 顺手就把我一个压根没打算动的仓库设置改了。它没使坏，它只是觉得这样更高效。那次之后我立了条规矩：每个 token 只给最小权限，90 天轮换一次。让 agent 免审批去碰真实网页，跟把一串钥匙又递出去一轮是同一件事，上一回钥匙碰出的娄子，我还记着。

它免的是谁的审批

官方说”自动批准它判定安全的动作”。做这功能的人不傻，他们配了一套安全分类器：一个查页面内容里有没有藏着注入的指令，一个查每个动作执行前符不符合你最初的要求，被标记了风险的就拦下来，或者暂停等你去批准。

我举个我自己的例子。我那条配图流水线，早期没把规则写死，我让 agent 给文章配图，它自作主张往正文里塞图床链接、还漏图。它每次都觉得是在帮我，它自觉没错，可那不是我想要的。

这护栏我认。这条路本来就该配护栏，我那份较真不是杞人忧天。

但有一个字我想抠一抠：”安全”是谁判的？是它判定安全，不是我判定安全。它核实的依据是”这个动作符合你最初的要求”，可”符合我最初的要求”跟”我真愿意亲手点下去”，中间隔着一段。我让它”把这份表填了”，它理解成”填完顺手点提交”，你说它错没错？没错。可我可能只想要它填，提交那一下，我想自己来。

所以这块开关，表面是”免了审批”，底下是”闸从你手里挪到了它手里”。它免的，只是它判定安全的那部分。可它判定安全的地方，恰恰是我有时想亲手掐掉的。

我会让它点到哪一步

这么一捋，我该放多少手就有数了。

能重来的、可回看的，全交。扒数据、读正文、搬信息，这些它免审批我放心，点错了刷新就回来，代价为零。

会改状态、会发出去、按下去收不回的那一下，我攥着。提交、删除、发送、付款，我不交给”自动批准”，宁可它停下来问我一句。它免审批是它的功能，我的闸是我得自己补的。它把逐点确认那道省了，我就在心里加一道：只放低风险、可重来的网页，撤不回的那一下我自己按。说真的，这个习惯不是我矫情。我那条发稿流水线，从选题、写稿、配图到排版全是 agent 自动跑，可最后推到公众号后台那一按，我从没交给它。前面出岔子删了重跑就是，后台那一按是我的脸面，我宁可自己来。

上个月我说”只敢让它看”。这个月它免审批了，我给它挪进”敢让它动”那一半，但只限能重来的那类。等我真拿它跑一轮真活、摸清它的脾气，再回来补一篇。要是这台能看屏自己点的它，在低风险页上稳得像它写代码那样，我就敢再往前推一寸。这事想明白，它免审批那点兴奋，就淡了一半。工具替你多开一扇门，你得自己多想一步：门后面，是谁替你踩刹车。想明白这一步的人，才配让它多开那扇门。

想问问你：哪些活你敢让它在浏览器里自己点？还是跟我一样，先让它”看”，”动”的事再慢慢谈？评论区聊聊。
