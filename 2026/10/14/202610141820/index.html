说真的，便宜六成 11 月 30 号就到期

发表于 2026-10-14 更新于 2026-10-17 分类于 观点 阅读次数： 本文字数： 3.4k 阅读时长 ≈ 3 分钟
Gemini 4 Argon 每任务成本 $1.99 是 GPT-6 Astra 的六成，可这便宜来自 Google 的 50% 促销折扣而非模型效率，11 月 30 号一过就翻倍到 $3.98，反超 Astra。

Hello，我是飞飞。

这几天你的信息流里，大概率刷到过同一句话：Google 的新模型追平了 GPT-6，账单只要六成。

数字有出处。评测机构 Artificial Analysis 白纸黑字写着：Gemini 4 Argon 每任务成本 1.99 美元，是 GPT-6 Astra 的六成。两边的智能指数同为 53 分。

我先给结论：这个六成是真的。但它的便宜来自 Google 主动打的那一刀，不在模型自己身上。而且它有一个写死的到期日。

十月四号那篇量的是同一家厂商两档模型之间的账。这次换个题型，量的是「每任务成本」这个指标本身。

这个六成是怎么来的

先把两个数摊开。Argon 最高思考档拿 53 分，Astra 最高档也是 53 分，同分。成本那一栏，Argon 1.99 美元，Astra 3.26 美元。

这个「每任务成本」不是谁跑完之后拿账单算的。Artificial Analysis 的方法学页写得清清楚楚。一次任务消耗掉三种 token：输入、缓存、输出。三种各自乘上对应的挂牌价，加起来，再除以任务数。

分子是量出来的，乘数是标价。说白了，这个数上拧着两个旋钮：一个是它吐多少 token，一个是每 token 多少钱。前一个我能从数据里看见，后一个的旋钮在 Google 手里。

换成生活里的说法：饭是它吃的，我数得清；米价是店家定的，我改不了。

同一套任务集不变，只要标价动一动，结论就跟着动。

功劳记在折扣头上

最狠的一句是 Artificial Analysis 自己写的。他的原话翻成中文是这样：这个成本优势来自更低的 token 价格，而不是更少的 token 用量。

后面还跟了一句铁证。Argon 每完成一件活，平均要吐 62000 个输出 token。Astra 是 27000 个。话多的是它，多出一倍还多。

也就是说，在用量这一头，Argon 是输的。它全靠标价那一头赢回来。Google 给这个模型打了对折，1.99 这个数就是拿对折价算出来的。

这里得说清一件事。十月四号那篇里我列过一张四口径的表。同一个 Sonnet 5.5，四个来源四个价。Artificial Analysis 给的 7.60 美元，是表里最贵的那个。

这两次不是同一个模型，别误会成同一个数变了。十月四号那个数看着贵，是因为它吐得多。Artificial Analysis 自己那档，一件活数到 19.3 万输出 token。用量那头炸了。这次这个数看着便宜，是因为 Google 主动让了价。公式没动，我该盯的旋钮换了。

这便宜只卖到 11 月 30 号

新的问题来了：Google 让的这个价，让多久。

9 月 30 号第一次发布的时候，谁都不知道期限。Artificial Analysis 那篇里写的原话是「Google 还没确认促销什么时候结束」。评测机构手里没有这个日期。

十三天后，Google 把日期补在了发布博文的脚注里。原话是：促销期在 2026 年 11 月 30 号结束后，4 美元输入、20 美元输出的价格开始生效。

评测机构不知道这个数什么时候到期，卖模型的那家知道。

Artificial Analysis 顺手把涨价后的账也算了出来。同一个模型，同一套任务，吐的 token 一个没变，每任务成本从 1.99 涨到 3.98。Astra 是 3.26。

从比 Astra 便宜四成，翻成比 Astra 贵两成。模型一个字都没改。

这种「用一个以后可能不存在的价格算名次」的事，这个指标之前真出过。Artificial Analysis 按计划中的 3 美元输入、15 美元输出算，把 Sonnet 5 的每任务成本定成 2.29 美元，比 Opus 4.8 的 1.99 美元贵。可 Anthropic 后来取消了那次涨价，把 2 美元输入、10 美元输出改成了长期价。名次已经发出去了，那个价格从来没存在过。

一个模型，六个价

同一个模型，同一档思考强度，同一周。几家机构给出的每任务成本是这样的。

来源 每任务成本 用什么价 量的是什么活
Zapier 自动化基准 $0.85 促销价 短的自动化任务，几下就完
Zapier 自动化基准 $1.70 标准价 同上
Artificial Analysis $1.99 促销价 通用智能指数
Artificial Analysis $3.98 标准价 同上
Vals AI 指数 $15.68 标准价 按行业占美国 GDP 比重加权
Vals AI 电脑操作分项 $193.78 标准价 模型一步步点鼠标、看屏幕

Zapier 那两个数，取自它 9 月 30 日的 AutomationBench 快照。

最便宜到最贵，差 228 倍。全用标准价的那三个，1.70、3.98、15.68，也差着 9 倍。

这里没有一个数造假。它们量的是不同的活。发新闻稿的那一方，挑的是最好看的那个。

同一个模型两家结论相反

标准价这一栏里，两家给的是相反的结论。

Artificial Analysis 说，标准价下 Argon 比 Astra 贵两成。Vals AI 说，标准价下 Argon 每次测试 15.68 美元。排在它前面的三个 Claude 模型要 21.34 到 32.14 美元，它反而更便宜。

同一个模型，同一个价格前提，两家机构给出相反的贵贱。

两家总有一家错了吧？谁都没错。两家的任务集不一样。一家考的是通用智能指数，一家按行业占美国 GDP 的比重加权。金融一项就占了一半以上。指标的口径不同，贵贱就会换边。

而且这个数自己也会飘。今年五月，Artificial Analysis 的 Coding Agent Index 里，Claude Code 里的 Opus 4.7 每任务 4.10 美元，Codex 里的 GPT-5.5 是 4.82 美元，Claude 这边赢。到了八月十号，同一个榜上这对模型变成 5.63 和 5.05，输赢反了过来。机构自己给的原因是：每任务成本会按当前 token 价格和刷新过的跑批重新计算。价格没变、跑批刷新，名次就能翻。

它最弱的那项之一，也最贵

不能只报喜。

Vals AI 有个电脑操作的基准，考模型直接操作图形界面干活。Argon 在这项拿了 4.83%，八个模型里排第七，倒数第二。

而这一项的单次成本，193.78 美元。全场最贵的一项之一，也是它最弱的一项之一。

还有个附加条件。在 Artificial Analysis 的 AA-Omniscience 基准上，它一本正经编瞎话的比例是 15%，在 45 分以上的模型里最低，靠的是「宁可说不知道」。代价是同一项准确率只有 50%，比 Astra 的 63% 低 13 个百分点。

我为什么不打算切

说回我自己。

我主力走的是 Claude Max 订阅，按月交固定的一笔，不按 token 计费。所以榜单上这些美元数，兑现不到我的月费上，它兑现成额度。

真要换，最贵的那笔从来不在 token 上。我这套写作流水线是十几个自己写的 skill、一份越喂越厚的 CLAUDE.md 工作说明、一摞记忆堆出来的。整套长在 Claude Code 的插件和钩子机制上。换个底座，等于把地基刨了重浇。光那套专门防 AI 味的文本过滤规则重新调顺，就够我搭进去好几个晚上。

这笔账我七月真算过。那晚我照例点开用量页面，一条斜线杵在那儿：一篇稿子，月度额度的 19%。我盯着那格看了半天才回过神：六个 skill 全长在 Sonnet 上，连搜几个关键词、抓几个网页这种活也是。后来按任务分档，写字和润色留在贵的那档，搜料、配图、分发压到便宜档。再跑一篇，那格几乎没动，停在 8% 到 9%。你要是也在按月付费，这个页面你手里也有一份，只是那格数字，你多半从没看过。

省下来的一半多，跟今天这个六成是同一个道理。别让贵档干便宜活。

我一周在 Claude Code 里烧掉 2800 万 token，按 API 裸价折算是 106 美元。这个量，按月付的人和按量付的人读出来，完全是两个意思。

以后你看这类数怎么读

十月四号那篇里我给过一套四步的读法：单价栏填没填、每任务成本、每任务输出 token、样本量和误差棒。今天在它后面补上这几条。

  • 这个数用的是什么价，挂牌标准价，还是限时促销价
  • 那个价有没有写期限，期限一到它变成多少
  • 两家机构结论相反时，先看它们的任务集是不是同一套

补完这几步，「六成」这种话你就不会直接信了。你会先问它是谁的六成，能撑几天。

因为「每任务成本」这个算法本身没毛病。它把用量和标价都算进去了，比单看单价诚实得多。问题在于那个旋钮不在我手里，拧它的人随时可以拧。

一个数只要有一个旋钮在别人手里，它就有一天会变。

11 月 30 号那天，1.99 变成 3.98。模型一个字没改。

你最近一次因为单价便宜动过换模型的念头，是什么时候？评论区说一下那个模型的单价，还有你实际跑完一件活之后的感觉。我帮你看看这笔账值不值。
